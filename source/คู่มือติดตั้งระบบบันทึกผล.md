# คู่มือติดตั้งระบบบันทึกผลการทดสอบ Herbal ERP · โรงงานผลิตยาสมุนไพรเรณูนคร (14 ต.ค. 2569)

ระบบมี 2 ส่วน
- **หน้าเว็บ** (`web/`): เผยแพร่ด้วย GitHub Pages เปิดได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ
- **หลังบ้าน** (`apps-script/Code.gs`): Google Apps Script ผูกกับ Google Sheet ที่เก็บผลทดสอบ

ผลทดสอบและภาพที่แนบเก็บใน Google Sheet / Google Drive ของทีม BMS เท่านั้น ไม่เก็บใน GitHub
ระบบที่ทดสอบ: ระบบ Herbal ERP สำหรับทดสอบ (ลิงก์ส่งให้ทางไลน์/อีเมล) ไม่ใส่ที่อยู่ไว้ในหน้าเว็บหรือ repository

## ติดตั้ง / เผยแพร่ (ครั้งแรกและครั้งต่อไปใช้คำสั่งเดียวกัน)

```
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1
```

สคริปต์ทำครบ: สร้างไฟล์จาก `data/cases-renu.json` > สร้าง Google Sheet และ Apps Script (ครั้งแรก) > push > deploy เว็บแอป
(เรียกใช้ในฐานะ: ฉัน · ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน) > เขียน URL `/exec` ลง `web/config.js` > push หน้าเว็บขึ้น
`santibms/herbal-erp-renu-test-2569` > เปิด GitHub Pages > แสดงลิงก์
รันซ้ำได้: ใช้ชีต สคริปต์ URL `/exec` และ repository เดิม (รหัสเก็บใน `apps-script/.clasp.json` และ `apps-script/.deployment.json`)

ก่อน push สคริปต์ตรวจไฟล์ที่จะเผยแพร่ ถ้าพบที่อยู่ระบบที่ทดสอบ อีเมลจริง หรือรหัสเชิญ จะหยุดทันที

**ครั้งแรกต้องทำเพิ่ม 1 ขั้น**: เปิด URL `/exec` ที่สคริปต์แสดง ด้วยบัญชี Google เดียวกับที่ใช้ clasp > อนุญาตสิทธิ์
(หรือเปิด Apps Script > เลือกฟังก์ชัน `setup` > เรียกใช้ > อนุญาต) แท็บในชีตจะถูกสร้างให้เอง
ตรวจว่าพร้อมแล้ว: `publish.ps1 -CheckOnly`

ต้องมีก่อนรัน: เข้าระบบ clasp (`npx -y @google/clasp@latest login`) · เปิด Apps Script API ที่ https://script.google.com/home/usersettings · เข้าระบบ `gh`

## แท็บใน Google Sheet

`ผลทดสอบ` `ประวัติการบันทึก` `สรุป` `ผู้ทดสอบ` `ข้อทดสอบ` `ตั้งค่า` (และ `คำชี้แจงผู้ดูแล` เมื่อผู้ดูแลบันทึกคำชี้แจงครั้งแรก)
ฟังก์ชัน `setup` เรียกซ้ำได้: สร้างเฉพาะแท็บและค่าที่ยังไม่มี ไม่ทำข้อมูลซ้ำ

| รายการในแท็บ ตั้งค่า | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| รหัสเชิญ | จาก `.local-settings.json` (ไม่เผยแพร่) | ผู้ทดสอบใส่ตอนสมัครสมาชิก |
| รหัสผู้ดูแล | สุ่มตอนติดตั้ง เช่น `BMS-1A2B3C4D` | สมัครโดยติ๊ก "สมัครเป็นผู้ดูแลระบบ" เห็นแดชบอร์ดสรุปผล |
| รุ่นโปรแกรมปัจจุบัน | `v1.6.84` | ค่าเริ่มต้นของช่องรุ่นโปรแกรม (ผู้ดูแลแก้จากแดชบอร์ดได้) |
| อายุการเข้าระบบ (ชั่วโมง) | 72 | เข้าระบบครั้งหนึ่งอยู่ได้นานเท่านี้ |
| โฟลเดอร์ภาพแนบ | สร้างตอนติดตั้ง | โฟลเดอร์ Drive `ภาพแนบ ผลทดสอบ Herbal ERP เรณูนคร 14 ต.ค. 2569` |

## ระหว่างการทดสอบ (ทีม BMS ทำใน Google Sheet)

| ต้องการ | ทำที่ |
|---|---|
| อัปเดตโปรแกรมเป็นรุ่นใหม่ | แดชบอร์ด > รุ่น Herbal ERP > บันทึกรุ่น (หรือแท็บ `ตั้งค่า`) ข้อที่บันทึกแล้วคงรุ่นเดิม |
| เพิ่มข้อทดสอบ | แท็บ `ข้อทดสอบ` > เพิ่มแถวต่อท้าย (รหัสข้อห้ามซ้ำ) > ผู้ทดสอบกดรีเฟรช |
| ซ่อนข้อทดสอบ | แท็บ `ข้อทดสอบ` > ช่อง **แสดง** = ไม่แสดง (ผลที่บันทึกแล้วยังอยู่) |
| ผู้ทดสอบลืมรหัสผ่าน | แท็บ `ผู้ทดสอบ` > ช่อง **รหัสผ่านชั่วคราว** |
| ให้สิทธิ์ผู้ดูแล / ระงับบัญชี | แท็บ `ผู้ทดสอบ` > ช่อง **บทบาท** / **สถานะ** |

## แก้ข้อทดสอบภายหลัง

แก้ `data/cases-renu.json` แล้วรัน `rebuild-cases.ps1` (สร้างไฟล์ > ทดสอบในเครื่อง > เผยแพร่ทับของเดิม)
หลังบ้านปรับแท็บ `ข้อทดสอบ` ให้เองเมื่อมีคำขอแรก ข้อที่เอาออกจะเป็น "ไม่แสดง" ผลที่บันทึกแล้วไม่หาย
